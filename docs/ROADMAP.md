# Roadmap

Explicitly **out of scope for the MVP**. Listed so the vision is visible without
inflating the build.

## Not built in the MVP

| Item | Why it is deferred | Signals it is worth building next |
| --- | --- | --- |
| Employer marketplace | Needs supply (verified graduates) and demand (employers) at the same time |Universities asking for placement exports |
| Verified skill passport (AI-graded projects) | Grading needs calibration and human review before it can be trusted | Students requesting shareable credentials |
| Live job-scraping pipeline | Terms of service and licence risk; needs legal review | A permitted source with a public API |
| Payments | No price validation yet | Students asking to save or export more than one plan |
| Mobile app | Web-first is enough to validate demand | Majority mobile traffic with high return rate |
| Voice interface | Bangla ASR quality and cost | Strong demand from low-literacy or low-bandwidth users |

## Beyond the MVP (post-competition)

1. University dashboard with cohort analytics (k-anonymity, minimum cohort 5).
2. Employer talent search over opt-in profiles.
3. Workforce analytics for NGO / government partners.
4. Regional expansion: Nepali, Hindi, Tamil UI with the same scoring core.
